# Changelog

## 0.0.3-pre

- Добавлен взаимоисключающий выбор оплаты: ручное подтверждение администратора или автоматическая ЮKassa.
- Добавлена безопасная серверная проверка уведомлений ЮKassa, идемпотентное создание платежа и автоматическая выдача подписки.
- Сайт и Telegram-бот показывают единый активный способ оплаты.
- Локальные копии, Backup-агент и ссылка на центральный Backup-сервер объединены в одну графическую панель администратора.
- Обновлена графическая панель Backup-сервера и мастер настройки секретов оплаты.
- В админ-панель добавлен отдельный раздел оплаты: ручная ссылка, Shop ID, секретный ключ, API URL и URL возврата.
- Настройки сайта автоматически используются подключённым Telegram-ботом; платёжные секреты в API бота не передаются.
- Автоматическое обновление из GitHub временно отключено; обновление из локального каталога сохранено.

## 0.0.2

- роли «Backup-сервер» и «Backup-агент» разделены в общем установщике;
- backup-сервер больше не требует ключ первого рабочего сервера при установке;
- в GUI добавлены отдельные кнопки «Добавить сервер» и «Удалить сервер»;
- добавлено временное отключение и повторное включение приёма копий;
- удаление сервера требует ввода его ID и отдельно предлагает удалить архивы;
- при безопасном удалении архивы переносятся в закрытый карантин;
- старые профили `0.0.1-pre` автоматически дополняются публичными ключами;
- установщик backup-агента проверяет SSH host key хранилища;
- обновление backup-агента сохраняет профиль, ключи и локальные архивы;
- добавлена полная инструкция чистой установки, обновления и внедрения в существующую систему.
- backup-панель получила выбор конкретного сервера и фильтры по типу регистрации;
- серверы теперь явно отмечаются как «добавлен в GUI» или «только обнаруженные архивы»;
- для обнаруженного каталога доступна регистрация в GUI с заранее заполненным ID;
- сводка отдельно показывает управляемые профили и старые каталоги архивов.
- серверы объединяются в карточки независимых конфигураций проекта;
- внутри конфигурации отдельно показаны сайт, Telegram-бот, основная и дополнительные 3x-ui-ноды;
- архивы остаются разделёнными по серверам и раскрываются внутри общей карточки;
- добавлены создание и редактирование состава конфигурации через GUI.

## 0.0.1-pre — предварительный выпуск

- единый компонентный мастер установки;
- обнаружение уже установленных компонентов;
- отдельные режимы установки, обновления и перенастройки;
- полное удаление проекта с отдельным подтверждением очистки данных;
- независимая установка сайта, Telegram-бота, домена/TLS, почты и backup-ноды;
- безопасное создание нового VLESS XHTTP/TLS или VLESS TCP/REALITY inbound;
- проверка конфликта порта и предварительный просмотр до записи в 3x-ui;
- локальный сайт-заглушка для пограничного сервера;
- отдельная HTTPS-панель мультисерверных резервных копий;
- независимые SSH-ключи и каталоги для RU, PL, тестовых и production-серверов;
- переносимые архивы v2 с полным состоянием приложения и заменой IP при восстановлении;
- сохранение баз, `.env` и конфигурации меню при обновлении;
- отдельная панель Telegram-бота с редактором приветствия, кнопок и порядка меню.
