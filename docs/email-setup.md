# Почта HOME-VPN

Сайт поддерживает регистрацию с подтверждением e-mail, вход по адресу почты, восстановление пароля и уведомление о входе. Рекомендуем использовать внешний SMTP-релей: для сервера с 2 ГБ RAM это надёжнее и легче, чем собственный почтовый стек.

## Переменные окружения

Добавьте в `/etc/vpn-shop.env`:

```dotenv
SMTP_HOST=mail.my.domain.ru
SMTP_PORT=587
SMTP_USERNAME=support@my.domain.ru
SMTP_PASSWORD=APP_PASSWORD_FROM_PROVIDER
SMTP_STARTTLS=1
SMTP_SSL=0
IMAP_HOST=mail.my.domain.ru
IMAP_PORT=993
IMAP_USERNAME=support@my.domain.ru
IMAP_PASSWORD=APP_PASSWORD_FROM_PROVIDER
IMAP_SSL=1
MAIL_FROM=support@my.domain.ru
MAIL_REPLY_TO=support@my.domain.ru
```

Для порта 465 используйте `SMTP_SSL=1` и `SMTP_STARTTLS=0`. Пароль приложения нельзя сохранять в Git.

После изменения:

```bash
systemctl restart vpn-shop
```

После первого входа администратора эти параметры можно сохранить и проверить через раздел **Почта → Настроить SMTP и IMAP**. Секреты в базе шифруются ключом, производным от `SESSION_SECRET`; изменение `SESSION_SECRET` без повторного ввода почтовых паролей сделает сохранённые секреты недоступными.

Встроенный почтовый клиент показывает последние входящие сообщения, позволяет отвечать и отправлять новые письма. Рассылки выполняются в фоне:

- «Подписались на новости» — только пользователи с явным согласием;
- «Клиенты с действующей подпиской» — только сервисные уведомления.

## DNS домена

Точные значения DKIM и MX выдаёт выбранный почтовый провайдер. В DNS-зоне `my.domain.ru` должны быть:

- MX — сервер приёма почты провайдера;
- SPF TXT — разрешённые серверы отправки;
- DKIM TXT — публичный ключ провайдера;
- DMARC TXT для `_dmarc.my.domain.ru`, сначала с политикой мониторинга `p=none`, после проверки — `quarantine` или `reject`.

Не публикуйте произвольные SPF/DKIM значения: они должны точно совпадать с SMTP-провайдером. Для собственного SMTP также нужны публичный IP, открытый исходящий TCP/25 и PTR/rDNS, настраиваемый владельцем IP.

## Проверка

Зарегистрируйте отдельный тестовый аккаунт на внешнюю почту и проверьте:

1. письмо подтверждения;
2. вход по адресу почты;
3. письмо о входе;
4. восстановление пароля;
5. SPF, DKIM и DMARC в заголовках полученного письма.
