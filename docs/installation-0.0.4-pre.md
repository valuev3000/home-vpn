# HOME-VPN 0.0.4-pre — установка на VPS

Версия поддерживает три схемы:

1. Центральная RU VPS с сайтом, Telegram-ботом, web-панелями и любое число зарубежных VPN-нод.
2. Та же схема с каскадом через центральную VPS.
3. Одна зарубежная VPS, на которой работают сайт, Telegram-бот и VPN.

Для установки используйте универсальный мастер:

```bash
python3 scripts/install-home-vpn-topology.py \
  --write-plan topology.local.json
```

После проверки плана:

```bash
python3 scripts/install-home-vpn-topology.py \
  --config topology.local.json \
  --apply \
  --confirm 'INSTALL HOME VPN TOPOLOGY'
```

План содержит SSH-имена VPS, сетевые адреса и домены, но не содержит паролей и
API-токенов. Для внешнего установщика набора протоколов обязательно укажите
HTTPS-адрес и предварительно проверенную SHA-256 сумму. Значение из примера
является заглушкой и перед применением должно быть заменено.

На центральной RU VPS размещаются сайт, API, Telegram-бот и все HOME-VPN
web-панели. На каждой зарубежной VPN-ноде создаются 11 подключений и простой
сайт-заглушка. Telegram API-трафик распределяется по кругу между доступными
VLESS/XHTTP-выходами; отказавшие узлы исключаются проверкой состояния.
Технический API 3x-ui каждой иностранной ноды должен быть доступен только
центральной VPS через защищённую межсерверную сеть.

В каскадном режиме путь выглядит так:

```text
пользователь → центральная VPS → зарубежная VPS → интернет
```

Каждой зарубежной ноде при каскаде нужен отдельный входной IP на центральной
VPS. Административные панели и Telegram-бот через каскад не перенаправляются.

Подробная архитектура, ограничения и команды проверки приведены в
[topology-installation.md](topology-installation.md). Резервное копирование и
восстановление описаны в [backup-and-restore.md](backup-and-restore.md).
