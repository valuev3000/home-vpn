# HOME-VPN 0.0.3-pre — установка и обновление

Это предварительная версия. Перед обновлением рабочего сервера создайте и выгрузите проверенную резервную копию.

## Новая установка

Требования: Debian 12, установленная и работающая 3x-ui, домен с HTTPS, Python 3 и доступ root. В примерах замените `192.168.1.50` на IP своего сервера, а `my.domain.ru` — на свой домен.

```bash
git clone <URL-ВАШЕГО-РЕПОЗИТОРИЯ> home-vpn
cd home-vpn
sudo bash install.sh
```

Мастер позволяет установить сайт, Telegram-бот, домен/TLS, почту, Backup-сервер и Backup-агент. Секреты сохраняются только в `/etc`.

После установки:

```bash
sudo home-vpn-manager status
sudo home-vpn-setup doctor
sudo systemctl status vpn-shop vpn-bot --no-pager
```

Подробное описание компонентов, узлов, TLS, почты и восстановления сохранено в [инструкции 0.0.2](installation-0.0.2.md); команды совместимы с 0.0.3-pre.

## Обновление 0.0.2

Автоматическое обновление и загрузка кода из GitHub временно отключены. Подготовьте локальную копию нужной версии проекта и выполняйте обновление только из неё:

```bash
cd home-vpn
sudo systemctl start home-vpn-backup.service
sudo python3 scripts/home-vpn-manager.py update site bot backup backup-agent
sudo home-vpn-setup doctor
```

Миграция базы выполняется приложением при первом запуске: создаётся таблица платёжных транзакций, существующие заказы и ручная оплата сохраняются. Режим по умолчанию — `manual`.

## Оплата

```bash
sudo home-vpn-setup payment
```

Одновременно активен только `manual` или `yookassa`. Полная настройка автоматической оплаты и webhook описана в [payment-yookassa.md](payment-yookassa.md).

После установки способ оплаты, ручная ссылка и параметры API изменяются на сайте: **Админ-панель → Оплата**. Подключённый Telegram-бот использует эти настройки через API сайта. Секретный ключ хранится зашифрованно и обратно в браузер или боту не передаётся.

## Единая панель резервного копирования

В админ-панели сайта откройте **Резервные копии**. Один экран показывает:

- локальные архивы и ручное восстановление;
- состояние локального расписания и Backup-агента;
- подключение к центральному Backup-серверу;
- кнопку перехода в графическую панель хранилища.

Подключить удалённое хранилище:

```bash
sudo home-vpn-setup backup-remote
```

Укажите IP/домен сервера, SSH-порт и URL его закрытой графической панели. На Backup-сервере конфигурация объединяет сайт, бота и ноды одного проекта, но архивы остаются раздельными по серверам.
